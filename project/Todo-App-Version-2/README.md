# Calculator Version 2.0

A modern calculator built using React and Bootstrap.

## Features

- Basic arithmetic operations
- Responsive UI
- Dark theme design
- Color-coded buttons
- Real-time display updates
- Clear (C) button
- Equal (=) button for calculations

## Technologies Used

- React.js
- JavaScript
- Bootstrap
- CSS3
- Vite
